# Skill naming standard

**Canonical document:** [`assets-blueprint/docs/standards/skill-naming.md`](https://github.com/krerapus/assets-blueprint/blob/master/docs/standards/skill-naming.md)

Skill names under `packs/core/harness/skills/` MUST follow `<action>-<object>[-<context>]` (lowercase, hyphens only). Do not encode Agent role, model/provider, client/runtime, version, or redundant suffixes (`-skill`, `-agent`, …).

Inventory: [`assets-blueprint/docs/skills.md`](https://github.com/krerapus/assets-blueprint/blob/master/docs/skills.md). Architecture: [architecture-split.md](../architecture-split.md).
